# LoxBerry Plugin Frontend v3/v4 Template

## Ziel

Diese Vorlage hilft beim Aufbau eines neutralen LoxBerry-Plugin-Frontends für LoxBerry v3 und v4.

## Enthalten

- Perl-CGI Beispiel mit `form=main`, `form=settings`, `form=log`
- PHP Beispiel mit denselben Formularseiten
- horizontales LoxBerry-Menü über die integrierte Navbar
- PrimeIcons in den Demo-Buttons
- CSS mit v4-Tokens und v3-Fallbacks
- LoxBerry-gerechte Loganzeige über `showlog=plugin`
