# LoxBerry Plugin Frontend v3/v4 Template

## Goal

This template helps to build a neutral LoxBerry plugin frontend for LoxBerry v3 and v4.

## Included

- Perl CGI example with `form=main`, `form=settings`, `form=log`
- PHP example with the same form pages
- horizontal LoxBerry menu using the integrated navbar
- PrimeIcons in demo buttons
- CSS with v4 tokens and v3 fallbacks
- LoxBerry-friendly log view using `showlog=plugin`
