# Frontend Checklist

## Basic test

- Test `index.cgi?form=main`.
- Test `index.cgi?form=settings`.
- Test `index.cgi?form=log`.
- Test `index.php?form=main`.
- Test `index.php?form=settings`.
- Test `index.php?form=log`.

## Navigation

- Check whether the active Navbar item stays highlighted.
- After saving on the settings page, `form=settings` must remain active.
- The Navbar must be defined before `lbheader()` is called.

## CSS

- Check `.plugin-page` as the scope.
- Avoid unintended global selectors like `button`, `input`, `.ui-btn`.
- Check custom buttons and inputs for `data-role="none"`.
- Hard reload the browser cache.

## LoxBerry v3/v4

- On v3, check that jQuery Mobile controls are not broken.
- On v4, check that v4-like tokens and fallbacks work correctly.
- Check green Save button.
- Check red Stop button.
- Check neutral Restart button.

## Log list

- Create a demo log.
- Reload the log page.
- Check whether the log list is generated by LoxBerry.
- Check whether the logviewer button opens correctly.
- Check whether the LoxBerry-generated collapsible sections still expand and collapse.

## Automatic check

```bash
chmod +x scripts/check_frontend.sh
./scripts/check_frontend.sh .
```
